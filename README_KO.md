# 탭 클릭 후 닫기 (Chrome / Edge / 웨일 확장 프로그램)

현재 창의 탭을 순서대로 돌면서 **지정한 위치를 클릭 → 탭 닫기 → 대기 → 다음 탭** 을 반복합니다.
탭이 N개라면 N번 클릭하고 N-1번 닫습니다. **마지막 탭도 클릭하지만 닫지 않고 남깁니다.**

키보드 매크로(Ctrl+W, Ctrl+Tab 등)는 브라우저가 가짜 키 입력을 무시해서 동작하지 않지만,
이 확장 프로그램은 브라우저 API(`chrome.tabs`, `chrome.scripting`)로 직접 탭을 전환·클릭·닫기 때문에 동작합니다.

## 설치 방법

1. `tab-click-closer.zip` 을 받았다면 압축을 풉니다. (폴더 안에 `manifest.json` 이 있어야 합니다)
2. 주소창에 다음을 입력합니다.
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - 웨일: `whale://extensions`
3. **개발자 모드**를 켭니다. (Chrome/웨일은 오른쪽 위, Edge는 왼쪽 메뉴)
4. **압축해제된 확장 프로그램을 로드**(Edge: "압축 풀린 항목 로드")를 누르고 `tab-click-closer` 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 "탭 클릭 후 닫기"를 고정(📌)해 두면 편합니다.

## 사용 방법

1. 클릭할 대상이 있는 탭을 열고 확장 프로그램 아이콘을 눌러 팝업을 엽니다.
2. **[위치 지정]** 을 누르면 팝업이 닫히고, 페이지에서 마우스를 올린 요소가 빨간 테두리로 표시됩니다.
   클릭할 버튼(위치)을 클릭하면 저장됩니다. (Esc: 취소)
   - 저장되는 정보: CSS 선택자(id → 고유 속성 → nth-of-type 경로 순으로 생성) + 클릭한 페이지 좌표
   - 이때의 클릭은 페이지에 전달되지 않습니다(위치만 저장).
3. 팝업을 다시 열어 설정을 확인합니다.
   | 항목 | 설명 | 기본값 |
   |---|---|---|
   | 클릭 방식 | 요소(선택자) / 좌표(x, y) | 요소 |
   | 요소를 못 찾으면 좌표로 클릭 | 요소 방식에서 선택자에 맞는 요소가 없을 때 저장된 좌표를 클릭 | 켬 |
   | 첫 클릭 전 대기 (초) | 시작을 누른 뒤, 맨 처음 탭을 클릭하기 전에만 기다리는 시간 | 0 |
   | 탭 사이 대기 (초) | 탭을 닫은 뒤 다음 탭으로 넘어가기 전 대기 | 5 |
   | 클릭 후 닫기 전 대기 (초) | 클릭 후 탭을 닫기 전 대기 | 1 |
   | 요소 찾기 최대 대기 (초) | 페이지가 늦게 그려질 때 요소가 나타나길 기다리는 시간 | 5 |
   | 순서 | 현재 탭부터 오른쪽으로(끝에 닿으면 맨 왼쪽부터 이어서) / 맨 왼쪽 탭부터 | 현재 탭부터 |
   | 못 찾으면 | 중지 / 건너뛰기(그 탭은 닫지 않고 남겨 둠) | 중지 |
4. 처리를 시작할 탭(보통 첫 번째 탭)에서 팝업을 열고 **[시작]** 을 누릅니다.
   - 탭이 전환되면 팝업은 자동으로 닫히지만 작업은 백그라운드에서 계속됩니다.
   - 팝업을 다시 열면 진행 상황(예: `2/4 완료`)과 기록을 볼 수 있습니다.
   - 실행 중에는 툴바 아이콘 배지에 다음 실행까지 남은 초가 표시됩니다. (`…` = 지금 클릭/닫는 중, 100초 이상은 `2m`처럼 분 단위)
5. 멈추려면 팝업에서 **[중지]** 를 누릅니다.

## 동작 순서 (탭 4개 예시)

시작 시점의 탭 목록을 순서대로 기억한 뒤:

```
(첫 클릭 전 대기, 기본 0초)
탭1 활성화 → 대상 클릭 → (1초) → 탭1 닫기 → (5초)
탭2 활성화 → 대상 클릭 → (1초) → 탭2 닫기 → (5초)
탭3 활성화 → 대상 클릭 → (1초) → 탭3 닫기 → (5초)
탭4 활성화 → 대상 클릭 → 완료 (탭4는 닫지 않고 열어둠)
```

- 시작 후 새로 연 탭은 대상에 포함되지 않습니다.
- 안전장치: 창에 탭이 1개만 남은 상태에서는 절대 닫지 않습니다.

## 제한 사항

- `chrome://`, `edge://`, `whale://` 같은 브라우저 내부 페이지, 확장 프로그램 페이지, **Chrome 웹 스토어 / Edge 추가 기능 사이트**에서는
  스크립트를 실행할 수 없어 클릭할 수 없습니다. (설정에 따라 중지 또는 건너뜀)
- 클릭은 스크립트로 만든 이벤트(`isTrusted = false`)입니다. 봇 방지 검사가 있는 사이트(일부 결제/로그인/캡차 등)는 이런 클릭을 무시할 수 있습니다.
- 페이지 안의 iframe(다른 사이트 프레임) 속 요소는 지정·클릭할 수 없습니다. 최상위 페이지만 지원합니다.
- 선택자 방식은 페이지마다 구조가 같을 때 정확합니다. 페이지마다 구조가 다르면 좌표 방식이나 "좌표로 클릭" 대체 옵션을 쓰세요.
  좌표 방식은 창 크기·확대 비율·스크롤 위치가 달라지면 다른 곳을 클릭할 수 있습니다.
- 클릭 후 확인 창(alert/confirm)이 뜨는 사이트는 고려하지 않았습니다.
- 브라우저를 다시 시작하면 진행 중이던 작업은 중지됩니다.
- 대기 시간이 30초 미만이면 서비스 워커를 깨어 있게 유지하며 진행하고, 30초 이상이면 `chrome.alarms` 로 예약합니다.
  혹시 서비스 워커가 종료되더라도 백업 알람으로 약 30초 안에 이어서 진행합니다.
