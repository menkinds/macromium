# macromium

각 탭에서 지정한 요소를 클릭합니다. 마지막 탭을 제외한 탭은 닫은 뒤 잠시 기다립니다. 마지막 탭도 클릭하지만 닫지 않아서 그 창은 그대로 남습니다. 시작 후 첫 클릭 전에만 따로 기다릴 수 있습니다.

## 설치

1. [릴리스 zip](https://github.com/menkinds/macromium/releases/download/v1.2.0/macromium-v1.2.0.zip)을 받아 압축을 풉니다.
2. 주소창에 `chrome://extensions` 또는 `edge://extensions`를 입력합니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누르고, 압축을 푼 폴더를 선택합니다.
