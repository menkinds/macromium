# macromium

각 탭에서 지정한 요소를 클릭하고, 그 탭을 닫은 뒤 잠시 기다립니다. 같은 작업을 탭 개수보다 한 번 적게 반복해서, 탭 하나는 그대로 남깁니다.

## 설치

1. [릴리스 zip](https://github.com/menkinds/macromium/releases/download/v1.1.0/macromium-v1.1.0.zip)을 받아 압축을 풉니다.
2. 주소창에 `chrome://extensions` 또는 `edge://extensions`를 입력합니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누르고, 압축을 푼 폴더를 선택합니다.
